## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| **HTML5** | Structure & semantic layout |
| **CSS3** | Animations, transitions, dark/light theming via CSS variables |
| **Vanilla JavaScript** | Auth logic, navigation, canvas particles, confetti |
| **Canvas API** | Background particles & confetti animation |
| **Google Fonts** | Playfair Display, Crimson Pro, Cormorant Garamond |
| **Base64 Images** | All 10 family photos embedded directly in the HTML |

No frameworks. No dependencies. No build tools. Just one beautiful `index.html` file.

## 🚀 Deployment

This site is hosted via **GitHub Pages** from the `main` branch.

To deploy your own copy:
1. Fork this repository
2. Go to **Settings → Pages**
3. Set source to `main` branch, root folder
4. Your site will be live at `https://<your-username>.github.io/birthday-baba/`
